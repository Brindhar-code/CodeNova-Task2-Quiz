# 🌊 QuizNova — Interactive Quiz Website

**Think Smart. Play QuizNova.** ✨

QuizNova is a fun, interactive, and responsive quiz website developed as part of the **CodeNova Frontend Development Internship — Task 2**. It allows users to test their knowledge across multiple categories, explore different difficulty levels, and track their quiz performance.

## 🎯 Quiz Categories

- 💻 Tech & Coding
- 🌍 General Knowledge
- 🔬 Science
- 🔐 Cybersecurity

## ✨ Features

- 🎮 Multiple-choice quizzes
- 🎚️ Difficulty selection
- ⏱️ Countdown timer
- 💡 Hints and answer explanations
- 🏆 Score and accuracy tracking
- 📈 Best-score tracking
- 📝 Review of answers after each quiz
- 🔊 Sound controls
- 📱 Responsive design for different screen sizes
- 📤 Shareable quiz results

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, animations, and responsive layouts
- **JavaScript** — Quiz logic and interactivity
- **JSON** — Quiz question data

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The website should open at a local address similar to:

`http://127.0.0.1:5500/`

**Important:** Use Live Server to run the project because the website loads quiz questions from `questions.json`. Opening `index.html` directly with a `file:///` URL may prevent the questions from loading.
